# Visual Workflow Studio Feature Walkthrough

## User Flow

1. Navigate to **Workflow Studio** (`/dashboard/workflows`).
2. Click on items in the **Node Palette** to add AI Search, Reasoning, Generation, or Verification nodes.
3. Click and drag output ports onto input ports to build connection edges.
4. Click any node to open the **Node Inspector** drawer to edit label, payload JSON, and parameters.
5. Click **Run Workflow** to trigger execution in NestJS BullMQ queue.
6. Monitor live streaming logs and execution steps in the resizable bottom console.
