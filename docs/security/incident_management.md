# Security Incident Management — Phase AB

Automated incident lifecycle: DETECTED → TRIAGED → CONTAINED → RESOLVED. Severity levels: INFO / LOW / MEDIUM / HIGH / CRITICAL. Evidence (IPs, timestamps, payloads) stored immutably. Notifications dispatched within 30s of detection to Slack, Teams, Discord, email, SMS, and webhooks. CRITICAL incidents auto-trigger emergency AI circuit breaker and IP ban.
