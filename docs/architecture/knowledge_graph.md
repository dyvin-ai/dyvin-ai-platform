# Knowledge Graph Entity Extraction Architecture

## Overview

The Knowledge Graph module extracts canonical business entities (Companies, Products, Services, Persons, Facts) from web intelligence scans and visualizes their directed relationships.

## Components

- `KnowledgeController` (`/projects/:id/...`)
- `KnowledgeGraphExplorer.tsx` (SVG + Interactive Node Inspector)
- Extracted Semantic Facts & Provenance Table
