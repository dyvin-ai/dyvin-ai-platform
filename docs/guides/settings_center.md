# Settings Center — Phase F3

## Overview

The Settings Center serves as the central administrative hub for organization profile, workspace configuration, team members, RBAC matrix, user profile, security telemetry, notification preferences, feature flags, and audit logs.

## Tabs Implemented

1. **Organization**: Name, logo, metadata (`OrgSettingsTab`).
2. **Workspaces**: Project listing, domain management, creation modal (`WorkspaceSettingsTab`).
3. **Team**: Member table, search, role badges, invitation modal (`TeamSettingsTab`).
4. **RBAC**: Role hierarchy, capability matrix (`RbacSettingsTab`).
5. **Profile**: First/last name, avatar URL (`ProfileSettingsTab`).
6. **Security**: Active sessions, device fingerprints, revocation (`SecuritySettingsTab`).
7. **Notifications**: Per-category delivery toggles (`NotificationSettingsTab`).
8. **Feature Flags**: Dynamic rollout flags & strategy indicators (`FeatureFlagsSettingsTab`).
9. **Audit**: System audit trail, retention compliance, JSON export (`AuditSettingsTab`).
