# TypeScript & NestJS Coding Style Guide

- **Strict Type Checking**: `noImplicitAny: true`, `strictNullChecks: true`.
- **Naming Conventions**: PascalCase classes, camelCase methods/variables, kebab-case filenames.
- **DTOs**: Suffix with `Dto`.
- **Services**: Suffix with `Service`.
- **Controllers**: Suffix with `Controller`.
- **Repositories**: Suffix with `Repository`.
