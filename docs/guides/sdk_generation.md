# Multi-Language Client SDK Generation Guide

SDKs are generated automatically from the OpenAPI 3.1 schema via `openapi-generator-cli`:
- **TypeScript / Node.js**: `@dyvin-ai/sdk-typescript`
- **Python**: `dyvin-ai-python`
- **Go**: `github.com/dyvin-ai/sdk-go`
- **Java**: `com.dyvin.sdk`
- **C# / .NET**: `Dyvin.AI.SDK`
