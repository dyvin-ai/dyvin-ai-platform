# Changelog

All notable changes to the Dyvin AI project will be documented in this file.

---

## [1.0.0] - 2026-08-07

### Added
- Complete **NestJS Backend Platform** (Phases A–AB) with multi-tenant database schema, Prisma client, rate limiting, and real-time security threats integration.
- Complete **Vite/React/TS Frontend Platform** (Phases F1–F3) featuring welcome pages, robust onboarding step-by-step wizard, workspace switcher, team roles assignment, and security session controls.
- Integrated **Zustand** stores (`authStore`, `orgStore`, `workspaceStore`, `permissionStore`) and **React Query** hooks.
- Implemented 7-tier **RBAC permission matrix** with route guards.
- Monorepo structure setup, environment variable blueprints (`.env.example`), and Docker configurations.
- Public repository files: `README.md`, `LICENSE`, `CONTRIBUTING.md`, `SECURITY.md`, `ROADMAP.md`, and CI/CD GitHub Actions workflows.
